> **An AI-powered personalized companion designed to keep memories alive through meaningful conversations.**

EchoSoul is a full-stack AI companion project that allows users to create a personalized conversational experience inspired by the **personality, memories, and experiences of a loved one**.

The goal is to create a meaningful and emotionally personalized AI experience where conversations feel more familiar and connected.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Mayuu17/EchoSoul.git
```

### 2. Navigate to the project

```bash
cd EchoSoul
```

---

## 💻 Frontend Setup

```bash
cd client
npm install
npm run dev
```

The frontend will start using the Vite development server.

---

## ⚙️ Backend Setup

Open another terminal:

```bash
cd server
npm install
npm run dev
```

If your backend uses a different start command, use the command defined in `server/package.json`.

---

## 🔐 Environment Variables

Create a `.env` file inside the `server` folder.

Example:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_gemini_api_key
```

> ⚠️ Never commit your `.env` file or expose API keys publicly.
